# 年終愛筵報名

線上報名＋選桌網站（純 HTML / CSS / JS），資料存在 Google 試算表。

- 報名表：姓名、性別、身分（聖徒／福音朋友）、小區（霧峰／朝陽／其他）、備註
- 可一次幫家人報名，選桌時全家一起入座
- 選桌：20 桌、每桌最多 10 位（含桌長），桌子圖案上顯示桌長；點進去可看到該桌名單，已滿會顯示「已滿」
- 報名後會拿到 4 位數「修改碼」，可隨時換桌；換裝置時用「任一位家人的姓名＋修改碼」登入

## 檔案
| 檔案 | 說明 |
|---|---|
| `index.html` / `style.css` / `app.js` | 網站本體 |
| `config.js` | **唯一需要修改的設定**：後端網址、活動日期／時間／地點 |
| `apps-script/Code.gs` | Google Apps Script 後端（貼到試算表裡） |

`config.js` 的 `API_URL` 留空時是**示範模式**：資料只存在自己的瀏覽器，方便預覽外觀。

## 設定後端（約 5 分鐘）
資料存在 Google 試算表「17會所事務」的 **「年終愛筵桌次表與報名」** 工作表：
A–J 欄是報名名單（同一次報名的家人共用「家庭編號」與「修改碼」），L–M 欄是桌號與桌長（表頭與 20 桌已建好）。

1. 開啟 https://script.google.com → 「新專案」。
2. 把 `apps-script/Code.gs` 的內容整個貼上（取代原本的程式碼），儲存。
3. 上方函式選單選 `setup`，按「執行」，依指示授權（會要求存取試算表）。
4. 右上角「部署 → 新增部署作業」→ 齒輪選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
5. 部署後複製網址（結尾是 `/exec`），貼到 `config.js` 的 `API_URL`。
6. 到試算表 M 欄把「桌長1～桌長20」改成真正的桌長姓名，網站會自動更新。

> 之後若修改 `Code.gs`，要用「部署 → 管理部署作業 → 編輯 → 版本：新版本」重新部署，網址不會變。

每桌人數上限可改 `Code.gs` 最上方的 `CAPACITY`。

## 上線（GitHub Pages）
GitHub 儲存庫 → Settings → Pages → 選擇分支與 `/ (root)` → 儲存，就會得到公開網址，把它分享出去即可。
