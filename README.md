# 年終愛筵報名

線上報名＋選桌網站（純 HTML / CSS / JS），資料存在 Supabase。

**👉 架設步驟請看 [教學.md](教學.md)**

## 功能
- 報名表：姓名、性別、身分（聖徒／福音朋友）、小區（霧峰／朝陽／其他）、備註
- 可一次幫家人報名，選桌時全家一起入座
- 選桌：20 桌、每桌最多 10 位（含桌長），桌子圖案上顯示桌長；點進去可看該桌名單，已滿顯示「已滿」
- 報名後拿到 4 位數「修改碼」，可隨時換桌；換裝置時用「任一位家人的姓名＋修改碼」登入

## 檔案
| 檔案 | 說明 |
|---|---|
| `index.html` / `style.css` / `app.js` | 網站本體 |
| `config.js` | **唯一需要修改的設定**：Supabase 連線資訊、活動資訊 |
| `supabase/schema.sql` | 資料庫（貼到 Supabase 的 SQL Editor 執行） |

`config.js` 的 Supabase 設定留空時是**示範模式**：資料只存在自己的瀏覽器，方便預覽外觀。
